- ChatGPT: apoio ao planejamento da arquitetura RAG, organização das tarefas, revisão de código, análise de erros de integração, elaboração de documentação, organização dos entregáveis e interpretação dos resultados.

DECISÕES TÉCNICAS E MUDANÇA DE PROVEDOR
1. O projeto foi inicialmente preparado para utilizar Ollama Cloud, conforme o briefing, com autenticação via OLLAMA_API_KEY nos Secrets do Colab.
2. Nos testes realizados com os modelos Cloud escolhidos, a conta utilizada recebeu respostas HTTP 402. A política oficial atual do Ollama informa que o plano gratuito possui uso inicial limitado a determinados modelos e que o acesso a modelos adicionais pode exigir créditos por uso ou plano com créditos incluídos. O código 402 foi compatível com uma restrição de cobrança/créditos/acesso, mas não permite identificar sozinho a condição exata da conta.
3. Foi testada uma alternativa com Groq. A avaliação completa não foi viável devido ao limite de tokens por minuto (TPM) da modalidade gratuita encontrado durante os testes.
4. Para concluir a execução integral, a integração foi adaptada para Google Gemini Developer API, com a chave GEMINI_API_KEY armazenada nos Secrets do Colab.
5. O modelo gemini-3.5-flash-lite foi o modelo efetivamente validado para a execução concluída. Foram incluídos tratamento de falhas temporárias HTTP 503 e checkpoints para preservar o progresso da avaliação.

POLÍTICA DO OLLAMA — DISTINÇÃO ENTRE LOCAL E CLOUD
O uso local do Ollama executa modelos no hardware disponível e não consome créditos do Ollama Cloud. Já a modalidade Cloud tem cotas/créditos por uso: a faixa gratuita inclui uma quantidade inicial de uso e um conjunto limitado de modelos; modelos Cloud adicionais podem exigir créditos ou plano pago. A página oficial consultada em 13/11/2026 apresenta preços por milhão de tokens e créditos incluídos nos planos. Portanto, não se concluiu que todo Ollama seja pago nem que não exista modalidade gratuita. A dificuldade específica do projeto foi acessar os modelos Cloud selecionados na conta utilizada sem adicionar custo.
