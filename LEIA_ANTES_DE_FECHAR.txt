PASSOS
1. Extraia esta pasta em um local fácil, por exemplo, na Área de Trabalho.
2. Abra a pasta extraída.
3. Execute MONTAR_ENTREGA.ps1 com PowerShell. Caso o notebook e o JSON não estejam na pasta, o script abrirá uma janela para selecionar os arquivos que você já baixou.
4. O script copiará os arquivos para os nomes exigidos:
   - 1_Notebook_GS2026_2.ipynb
   - 3_avaliacao_ragas.json
5. Antes de gerar o ZIP, substitua o endereço de repositório em 5_certificacao.txt e o link do vídeo em 7_demo_video_url.txt.
6. Confira as assinaturas: cada integrante deve assinar sua própria declaração.
7. O script valida se os dois arquivos são JSON legíveis, se o notebook contém células executadas e se os links foram preenchidos. Se algo faltar, explica o que precisa corrigir.
8. Quando validado, será gerado GS2026_2_1CCPJ_TRAMA_CIVICA.zip com apenas os sete entregáveis oficiais.

PENDÊNCIAS QUE DEPENDEM DE VOCÊ/EQUIPE
- selecionar os arquivos já baixados quando o script pedir;
